# DS5Dongle RP2350B-Plus-W Fork

This repository contains a DS5Dongle-based firmware project under `ds5dongle/`. It imports the upstream project and adds a Waveshare RP2350B-Plus-W build target plus small latency/stability improvements for the DualSense Bluetooth-to-USB bridge workload.

See [`ds5dongle/README-WAVESHARE.md`](ds5dongle/README-WAVESHARE.md) for build commands, board support notes, and the current limitations.
